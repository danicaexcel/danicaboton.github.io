Google Workspace Project Operations System

A Google-native project management workspace that connects project planning, Gantt schedules, member task execution, planned-vs-actual man-hours, rework tracking, approvals, and labor-cost reporting. Google Sheets acts as the structured operational datastore while Apps Script controls task state, time punches, validation, notifications, and audit history.

What needed to change

Project plans and employee time records are often maintained separately. That makes it difficult to see whether a task exceeded its estimate, whether a project is consuming labor faster than it is progressing, or how much additional work came from revisions. Manual timesheets also make task-level labor costing harder to audit.

What I designed

I designed a Google Workspace operating model where every task starts with a planned man-hour budget. Members work from a dedicated view and use Start, Pause, Resume, Complete, and Revise actions instead of manually typing hours. Apps Script records each session, prevents overlapping active tasks, rolls actual time back to the task and project, and keeps rework separate from original execution.

Core modules

  • Project portfolio and project health dashboard
  • Project phases, task list, dependencies, and Gantt timeline
  • Member workspace with task punching and one-active-task control
  • Planned vs. actual man-hours and estimate variance
  • Revision / redo sessions recorded as additional rework hours
  • Timesheet review and approved-hours labor-cost input
  • Team capacity, project labor cost, and activity history

Google-native architecture

  • Google Sheets: structured tables for Projects, Tasks, Members, Sessions, Revisions, Timesheets, Rates, and Audit Logs
  • Apps Script: workflow state machine, timers, validation, aggregation, approvals, and notifications
  • Apps Script Web App: manager and member operating interface
  • Google Drive: project file links and deliverables
  • Google Calendar / Gmail: milestone, due-date, and approval notifications
