Custom recruitment agent platform

A separate AI action layer connected to the Zoho CRM recruitment system through controlled APIs and webhooks. Agents reason over recruitment context, call named tools, request approval where required, and write controlled outcomes back.

System boundary: these are custom agents outside Zoho Zia. File outputs are produced through explicit artifact tools; the public demo shows the tool invocation and artifact record, while a production backend returns the actual file.
