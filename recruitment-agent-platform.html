Custom recruitment agent platform

A separate AI action layer connected to the Project 01 Zoho CRM system through controlled APIs and webhooks. Agents reason over recruitment context, call approved tools, request human approval where required, and write outcomes back to Zoho CRM.

System boundary: Zoho CRM remains the system of record. These are custom agents orchestrated outside Zoho; they are not Zia Agents. The existing resume extraction + candidate scoring workflow is exposed as a reusable tool.
