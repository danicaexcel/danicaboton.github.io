Custom recruitment agent platform

Four user-facing recruitment agents sit over a cost-controlled specialist backend. n8n routes requests, schedules proactive work, invokes narrow GPT-4.1 nano / mini specialists, calls governed tools, and pauses sensitive actions for approval.

File handling: users can attach non-video files up to 25 MB per file. Agents can use attachments as context and create file outputs when requested through a governed file service—without exposing file-format buttons in the chat UI.
